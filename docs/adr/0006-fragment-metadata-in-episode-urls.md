# Carry playback API identifiers in `SEpisode.url` fragments

Anikku persists `SEpisode.url` permanently as the episode identity key in SQLite and opens `baseUrl + episode.url` directly for WebView browsing and link sharing, while DramaTip's `/api/episode-source/{bookId}/{serial}` endpoint requires `bookId`, raw `serial_number`, and `rawCatalog` that are not derivable from the public episode path alone. We format `SEpisode.url` as the real localized episode path plus a metadata fragment (`.../episode-{display}#bookId={bookId}&serial={rawSerial}&raw={0|1}`), preserving valid browser/WebView URLs while avoiding a redundant ~450 KB HTML fetch on every 60-second episode transition (falling back to scraping the page if the fragment is absent).
