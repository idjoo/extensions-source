# Embedded loopback HTTP proxy for manifest-rewritten and byte-encrypted providers

While most Upstream Providers on DramaTip stream standard HTTPS HLS or MP4 media, `GoodShort` and `IDrama` require rewriting `#EXT-X-KEY` URIs inside `.m3u8` manifests to DramaTip key endpoints, `ShortTv` (`hls-enc`) prepends a custom 1024-byte AES-CBC header to `.ts` segments, and encrypted `DramaBox`/`Storeel` MP4s AES-CBC encrypt `stbl` samples using a key stored in the `moov` box. Because Anikku permits cleartext localhost traffic (`cleartextTrafficPermitted="true"`), we run an on-demand NanoHTTPD server bound strictly to `127.0.0.1` (authenticated with a per-session token and idle auto-shutdown) solely for streams and subtitles requiring manifest rewriting or byte decryption, bypassing the proxy completely for standard direct streams.
